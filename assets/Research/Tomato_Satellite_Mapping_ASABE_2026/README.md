# Tomato Satellite Mapping — ASABE 2026

Research assets for:

**Mapping Tomato Cropping Systems in California Using AlphaEarth Geospatial Embeddings and Deep Learning Analysis**

Mohammadreza Narimani, Alireza Pourreza, and Parastoo Farajpoor  
ASABE Annual International Meeting 2026, Indianapolis, Indiana  
Poster presented July 14, 2026

## Source and web assets

- `Assets/Mohammadreza_Narimani_ASABE_2026_Main_Paper.pdf` — local paper source; gitignored because the public page directs readers to arXiv.
- `Assets/Mohammadreza_Narimani_ASABE_2026_Main_Poster.png` — local full-resolution poster source; gitignored to avoid serving a 55 MB image.
- `Assets/Mohammadreza_Narimani_ASABE_2026_Main_Poster_Web.jpg` — optimized poster preview displayed by the public web page.
- `Assets/Mohammadreza_Narimani_ASABE_2026_With_Poster.jpeg` — presentation photo.
- `Assets/Mohammadreza_Narimani_ASABE_2026_Explaining_Poster.jpeg` — poster-session photo.
- `Markdown/media/figure-001.png` — paper workflow figure.
- `Markdown/media/figure-003-web.jpg` — optimized U-Net architecture figure.
- `Markdown/media/figure-004.png` — representative predictions and uncertainty figure.

The paper figures were extracted from the PDF with Poppler `pdfimages`. Large figures were resized with Python Pillow for faster web delivery while preserving the original paper and poster files locally.
